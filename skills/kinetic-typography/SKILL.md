# Kinetic Typography

## Principles

Typography is the visual subject, not decoration.

## Build order

1. Choose type hierarchy.
2. Establish baseline/grid.
3. Define entrance, emphasis and exit.
4. Map important words to beats or narration.
5. Add secondary details only after the primary message works.

## Animation vocabulary

Use:
- fade
- slide
- scale
- reveal/mask
- tracking change
- line growth
- word stagger
- character stagger
- blur-to-sharp
- kinetic displacement

Use effects sparingly.

## Timing

Default logic:
- fast hook
- readable hold
- energetic emphasis
- clean exit

Never sacrifice legibility for speed.

## Professional checks

- sufficient contrast
- safe margins
- no awkward widows
- consistent tracking
- readable at target size
- hierarchy survives grayscale
