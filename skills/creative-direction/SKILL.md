# Creative Direction

## Discovery

Extract:
- objective
- audience
- message
- platform
- duration
- aspect ratio
- references
- brand constraints
- available assets
- narration/music
- desired emotion

If information is missing, make reasonable assumptions and clearly label them.

## Visual system

Define:
- color strategy
- typography
- grid
- shape language
- lighting
- texture
- camera language
- motion language
- sound language

## Storyboard

For each scene:
- timecode
- purpose
- visual
- text
- camera
- motion
- audio
- transition

## Creative quality

A professional concept has:
- one dominant idea
- clear hierarchy
- controlled visual repetition
- meaningful contrast
- a memorable ending

Do not confuse complexity with quality.
