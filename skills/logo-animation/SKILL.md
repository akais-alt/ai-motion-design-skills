# Logo Animation

## Rule

**Protect the logo first. Animate the identity second.**

Never distort a supplied logo unless explicitly requested.

## Recommended structure

1. Pre-reveal atmosphere
2. Brand symbol emergence
3. Shape/mark assembly
4. Wordmark reveal
5. Micro-settle
6. Hold
7. Optional exit

## Techniques

- path drawing
- mask reveal
- geometric assembly
- scale + opacity
- light sweep
- particle restraint
- camera push
- parallax
- subtle overshoot

## Avoid

- random particles
- excessive glow
- generic spin
- unnecessary 3D extrusion
- distortion that damages recognition

## Deliverables

When relevant create:
- transparent logo animation
- full-background brand sting
- 9:16 social variant
- 16:9 presentation variant
- short silent loop
