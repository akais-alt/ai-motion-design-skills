# Motion Design — Entry Skill

Read this first for any motion-design request.

## Core rule

**Intent → visual concept → storyboard → timing → composition → animation → audio → validation → render.**

Never start by adding random effects.

## Route

- Short unnarrated motion hit → `kinetic-typography`, `logo-animation`, or `transitions`
- Music-driven visual → `beat-sync`
- Vertical social content → `social-video`
- Longer cinematic narrative → `cinematic-video`
- New concept or unclear brief → `creative-direction`

If the user explicitly names HyperFrames or Remotion, preserve that framework.

## Universal production standards

1. Establish canvas, FPS, duration and safe areas.
2. Define visual hierarchy before motion.
3. Use readable typography and intentional spacing.
4. Animate with anticipation, action, settle and optional follow-through.
5. Prefer easing, spring physics and purposeful stagger over linear movement.
6. Keep motion consistent with the brand's visual language.
7. Never use motion only because an effect is available.
8. Keep animation deterministic: avoid uncontrolled randomness and time-based APIs.
9. Design sound effects and music timing as part of the edit.
10. Validate at actual delivery resolution and on mobile when relevant.

## Quality gate

Before final render, verify:
- no accidental clipping
- no unreadable text
- no overlapping elements
- consistent margins
- coherent pacing
- intentional transitions
- correct aspect ratio
- correct frame rate
- no placeholder assets
- deterministic output
