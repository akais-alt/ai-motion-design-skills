# AI Motion Design Skills

A production-oriented Agent Skills collection for AI-assisted motion design.

Designed for **HyperFrames, Remotion, Claude Code, Codex, Qwen, Cursor and compatible coding agents**.

## Included skills

- `motion-design` — universal entry point and workflow router
- `cinematic-video` — cinematic multi-scene storytelling
- `kinetic-typography` — expressive typography and text animation
- `logo-animation` — logo reveals, stings and brand systems
- `beat-sync` — music-driven timing and beat mapping
- `social-video` — TikTok / Reels / Shorts vertical production
- `transitions` — purposeful transitions and scene continuity
- `creative-direction` — concept, storyboard, visual language and art direction

## Installation

```bash
npx skills add akais-alt/ai-motion-design-skills --all
```

For a single skill:

```bash
npx skills add akais-alt/ai-motion-design-skills --skill motion-design
```

## Philosophy

The skills prioritize **design before code, timing before effects, composition before decoration, and deterministic rendering before visual randomness**.

They are framework-aware but framework-agnostic in creative direction. HyperFrames is preferred for HTML-based motion when requested; Remotion is preferred when the project is explicitly React/Remotion.
