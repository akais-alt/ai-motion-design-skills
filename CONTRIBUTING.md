# Contributing

## Add a skill

Create:

```
skills/<skill-name>/SKILL.md
```

Include:
- YAML frontmatter with `name` and `description`
- clear activation conditions
- workflow
- quality rules
- validation checklist

## Quality standard

Skills should teach an agent how to make a better creative decision, not merely list software commands.

Prefer concise, actionable rules over generic inspiration.

## Compatibility

Avoid provider-specific secrets or private credentials. Keep examples deterministic and portable.
